How it works

Every visitor paints on the same 10,000 × 10,000 canvas. Pixels are stored centrally and updates appear live. You can replace an existing pixel, but every placement uses your 10-second cooldown.

Public launch checklist: enable anonymous sign-in, run the included SQL setup, and add your Supabase project URL and anon key to config.js. Never put a service-role key in the browser.
