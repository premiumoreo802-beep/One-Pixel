How it works

Everyone paints on the same 10,000 × 10,000 canvas. Changes appear live. You can replace an existing pixel, but each placement uses your 10-second cooldown.

Setup: run supabase/schema.sql, disable email confirmation in Supabase Auth settings, and add your project URL and publishable/anon key to config.js. Never put a service-role key in browser code.
